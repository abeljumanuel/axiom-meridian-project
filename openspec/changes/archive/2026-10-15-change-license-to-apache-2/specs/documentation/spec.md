## ADDED Requirements

### Requirement: README states the Apache 2.0 license, trademark, and transition
`README.md`'s License section SHALL state that the project is licensed under the Apache License 2.0 with links to `LICENSE` and `NOTICE`, SHALL state that the project names and marks are not licensed (Apache-2.0 section 6), and SHALL state that versions made available before this change were declared under MIT and copies obtained under those terms remain available under them.

#### Scenario: License section content
- **WHEN** `README.md`'s License section is read
- **THEN** it names Apache License 2.0, links `LICENSE` and `NOTICE`, includes the trademark note, and includes the MIT transition note

### Requirement: Third-party components are identified
`README.md` SHALL include a third-party note stating that `.claude/skills/openspec-*` are generated by OpenSpec and keep their own MIT license, and those files SHALL remain unmodified.

#### Scenario: Third-party note and untouched files
- **WHEN** `README.md` is read and `git diff` is run over `.claude/skills/openspec-*`
- **THEN** the README contains the OpenSpec third-party note and the diff for those files is empty

### Requirement: No residual MIT declarations for Meridian itself
Outside third-party files and historical records, no file SHALL declare Meridian's license as MIT; the project charter and `docs/design/README.md` SHALL state Apache-2.0, and `docs/design/meridian-implementation-plan.md` SHALL keep its historical content with only an added note referencing this change.

#### Scenario: Residual grep
- **WHEN** `grep -rIw MIT` is run excluding `.git`, `.venv`, `uv.lock`, `.claude/skills/openspec-*`, `openspec/changes/`, and the transition/third-party notes in `README.md`
- **THEN** the only remaining match is the historical snippet in `docs/design/meridian-implementation-plan.md`, which is accompanied by the note pointing to this change

### Requirement: CHANGELOG records the relicense
A `CHANGELOG.md` in Keep a Changelog format SHALL exist with an `## [Unreleased]` section whose "Changed" entry records the license change from MIT to Apache-2.0.

#### Scenario: Changelog entry
- **WHEN** `CHANGELOG.md` is read
- **THEN** its `## [Unreleased]` section contains a "Changed" entry mentioning the MIT → Apache-2.0 relicense
